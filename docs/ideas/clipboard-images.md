# Clipboard images: ideas left for later

[ADR 0167](../adr/0167-paste-clipboard-image-in-the-explorer.md) pastes a clipboard image as a PNG in the explorer.
Left out:
- **Markdown editor paste:** save the image beside the file and insert `![](…)`.
- **File → New Scratch from Clipboard Image:** an image scratch without the explorer.
- **Other formats:** JPEG or WebP with a quality choice.
- **Copy Image:** from an image tab or the explorer onto the clipboard as image data.
