# Clipboard text: ideas left for later

- **A key for New Scratch from Clipboard:** Shortcut+Shift+V is the terminal's Paste.
- **Rich text and HTML:** pasting them as `.html`.
- **More languages in the detection:** Go, Rust, C#, and others.
