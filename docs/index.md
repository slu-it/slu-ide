# Thoreau documentation index

Entry point for agents: read this file first, then open only the documents relevant to your task.
Keep it up to date: every new ADR or feature description must be added here with a one-line summary.

## Overview
- [architecture.md](architecture.md) — Module layout, dependency rules, runtime startup, CI and release process.

- [testing.md](testing.md) — Unit vs. TestFX UI tests, `uiTest` task, running a subset of the tests, display handling locally and in CI, how to write UI tests, running and screenshotting the app in a headless sandbox.

## Decisions (ADRs)
- [adr/0001-tech-stack.md](adr/0001-tech-stack.md) — Kotlin on JDK 25, Spring Boot, JavaFX, Gradle multi-module build.
- [adr/0002-spring-inside-javafx.md](adr/0002-spring-inside-javafx.md) — A non-web Spring context is started and stopped by the JavaFX `Application`; UI parts are Spring beans; partly superseded by ADR 0014 (window beans created per window on the FX thread).
- [adr/0003-javafx-platform-jars.md](adr/0003-javafx-platform-jars.md) — JavaFX comes from the OpenJFX Gradle plugin; fat jars are platform-specific, so releases are built and published per OS/arch (no Windows).
- [adr/0004-file-viewer-selection.md](adr/0004-file-viewer-selection.md) — Viewers are asked in turn whether they can open a file, `DefaultTextFileViewer` last; no viewer means the file is not opened; partly superseded by ADR 0029 (of the viewers that agree, the best name match wins).
- [adr/0005-syntax-highlighting.md](adr/0005-syntax-highlighting.md) — Code views render with RichTextFX and tokenize with the RSyntaxTextArea lexers behind our own `SyntaxHighlighter`; small formats without a lexer as line rules on the plain lexer, which is skipped; alternatives considered; partly superseded by ADR 0031 (own tokenizers for larger languages without a lexer).
- [adr/0006-file-watching.md](adr/0006-file-watching.md) — JDK `WatchService` behind `FileWatcher`, watching only loaded folders, the folders of open files and the repository's `.git` (not recursive); combined events, watches renewed for recreated folders; macOS polls every 2 s.
- [adr/0007-terminal.md](adr/0007-terminal.md) — Terminals use pty4j and the JediTerm core (from JetBrains' repository, restricted to its group) with our own JavaFX canvas view; alternatives considered.
- [adr/0008-settings.md](adr/0008-settings.md) — Settings live in `modules/settings` as Spring beans with JavaFX properties, stored in `~/.sluide/settings.properties` (keys and formats; an unreadable file is never replaced); a setting changes only once stored; dialog built from `SettingsPage` beans.
- [adr/0009-themes.md](adr/0009-themes.md) — Light/dark/system theme: scene colour-scheme preferences, `theme.css` re-tinting Modena, `@media (prefers-color-scheme: dark)` rules only in stylesheets with their own colours; WebView pages follow ADR 0016; single-class selectors only in dark blocks.
- [adr/0010-docker-sandbox.md](adr/0010-docker-sandbox.md) — Docker sandboxes run as the process of a terminal tab, only in folders strictly below the home folder (real paths), checked in the menu and again on start.
- [adr/0011-native-app-packaging.md](adr/0011-native-app-packaging.md) — jpackage builds Thoreau.app / a disk image with a compressed jlink runtime (`:ide:jpackageImage`, `:ide:jpackageDmg`), attached to GitHub releases; not notarized, allowed once via Open Anyway; app and window icons rendered from `ide/packaging/thoreau.svg` by `render-icon.sh`.
- [adr/0012-file-icons.md](adr/0012-file-icons.md) — File explorer icons from Ikonli's Material Design Icons pack (one style), covering every file type icon of the pack, chosen by folder state, file name, extension and readability, coloured per type in CSS; pack comparison.
- [adr/0013-git-status.md](adr/0013-git-status.md) — Git status from `git status --porcelain=v2 --ignored` (no JGit, no own `.gitignore` parser), checked for at startup, followed only for folders with `.git`, refreshed in the background on explorer changes, F5 and changes directly in `.git`; a failed run keeps the last status; markers in the explorer; the standard error of reads is partly kept since [0060](adr/0060-logging-conventions.md); since [0062](adr/0062-git-concurrency.md) only changes of what the status reads refresh, and git writes hold refreshes.
- [adr/0014-project-windows.md](adr/0014-project-windows.md) — One project per window: Open Folder opens a new window unless the window has no folder yet; Spring scope `window` for per-window beans (`ProjectWindows`); one confirmation when closing a window with running tabs; partly superseded by ADR 0034 (the last window closing shows the project picker).
- [adr/0015-git-diff.md](adr/0015-git-diff.md) — Side-by-side diff against `HEAD` from `git diff -U0`/`git cat-file` (no diff library), synchronous per file, filler rows for aligned scrolling; partly superseded by ADR 0021 (files open in the editor with change markers, the diff on demand) and ADR 0062 (diffs off the JavaFX thread).
- [adr/0016-markdown-preview.md](adr/0016-markdown-preview.md) — Markdown preview: commonmark-java renders sanitised HTML (jsoup) into a JavaFX WebView beside the source; native JavaFX nodes rejected; javafx.web grows the fat jar by ~48 MB; partly superseded by ADR 0017 (pages that navigate on their own).
- [adr/0017-webview-previews.md](adr/0017-webview-previews.md) — One `PreviewFileView` (source beside a WebView) for all rendered formats; HTML loaded by URL from the local server (ADR 0018) with its scripts off by default, navigations without user input stop the preview; bundled KaTeX and Mermaid; notebooks rendered from their JSON.
- [adr/0018-html-preview-server.md](adr/0018-html-preview-server.md) — HTML previews are served from a loopback HTTP server confined to the project folder (no hidden files, no symlinks out), since `file:` pages' scripts can read every local file.
- [adr/0019-word-diff.md](adr/0019-word-diff.md) — Changed words within modified lines come from a small token LCS over each modified block of git's line diff (no `git --word-diff`, no library), earliest matches preferred, blocks over a million steps left out.
- [adr/0020-editing-and-saving-files.md](adr/0020-editing-and-saving-files.md) — Code, plain text and preview sources are edited in RichTextFX `CodeView`s (`EditableFileView`) with plain-text undo; dirty from the undo mark; explicit save in place keeping line endings; saved text as baseline for changes on disk (`DiskChange`: ignore, reload minimally, banner); prompts before closing; previews render on save; highlighting in the background after a pause.
- [adr/0021-change-markers-and-diffs-on-demand.md](adr/0021-change-markers-and-diffs-on-demand.md) — Files always open in the editor; `Gutter` replaces `LineNumberFactory` with line numbers, change markers from git's diff (`LineMarkers`, moved along with unsaved edits) and a column hook; the side-by-side diff of the saved file is shown on demand over the kept editor (View → Show Changes, Shortcut+Shift+D; Edit/Escape back; clicking a marker); partly supersedes ADR 0015; partly superseded by ADR 0062 (`diffOf` asynchronous).
- [adr/0022-editor-key-bindings.md](adr/0022-editor-key-bindings.md) — Editor keys as a wellbehavedfx `InputMap` per code view (precedence over RichTextFX's, only while the text has the focus, editing keys only while editable) rather than menu accelerators; Shortcut modifier; keys after IntelliJ/VS Code; Shortcut+/ by character, Shortcut+Shift+7 by key; one `TextEdit` = one undo step (Replace All: one multi-change); search on the FX thread within a 200 ms budget, at most 10,000 marked matches; no command registry yet.
- [adr/0023-indentation-from-editorconfig.md](adr/0023-indentation-from-editorconfig.md) — Indentation from `.editorconfig` via ec4j-core 1.1.1 (Apache-2.0, no dependencies, used by ktlint), each value else detected from the file, else the language's default (tabs for Makefiles, else 4 spaces); read when a file opens; no whitespace or final-newline rewrites on save.
- [adr/0024-file-operations-in-the-explorer.md](adr/0024-file-operations-in-the-explorer.md) — New file/folder, rename and delete in the explorer: `FileOperations` with checked single names, rename within the folder (case-only renames over a temporary name), permanent delete without trash behind a confirmation counting unsaved files; open tabs follow renames (`FileView.moved`, else reopened) and close after a delete.
- [adr/0025-http-client.md](adr/0025-http-client.md) — HTTP client module, the supported subset of IntelliJ's `.http` format, variable lookup order (dynamic, environment, in-file), body files and unresolved variables, unverified IntelliJ behaviours.
- [adr/0026-http-client-window-session.md](adr/0026-http-client-window-session.md) — Per-window `HttpClientSession` (cookies, tokens, clients, chosen environments) found through `FileViewHost.windowService`; the public code editor API of `file-viewers` (`CodeEditors`, `CodeEditor`, `CodeDisplay`, `SourceFileViewer`).
- [adr/0027-http-client-sending.md](adr/0027-http-client-sending.md) — Requests on the JDK `HttpClient` off the FX thread: restricted headers and `allowRestrictedHeaders=host`, defaults, decompression, 50 MB cap, redirects, timeouts, cookie jar, Basic and Digest, default proxy selector.
- [adr/0028-http-client-secrets.md](adr/0028-http-client-secrets.md) — Secrets only from the environment files (warning when git would commit the private one), OAuth2 grants and in-memory tokens per window (refresh, failures not cached), client certificates and passphrase prompts, trust-all per environment.
- [adr/0029-file-name-and-shebang-matching.md](adr/0029-file-name-and-shebang-matching.md) — Viewers match by extension, exact name or name pattern (exact name > extension > pattern, Spring order only for ties), extensionless files by shebang after all names; small formats without a lexer get line rules on the plain lexer, which is skipped; TOML, Bicep, KQL postponed, then given own tokenizers by ADR 0031.
- [adr/0030-masking-env-values.md](adr/0030-masking-env-values.md) — `.env` values are masked by a `masked` style overlay on the `CodeView` (text untouched, so copy/find/save/undo work), applied with every change; caret line and selected find match revealed, Show values toggle per tab; whole lines, hover reveal and masked diffs rejected.
- [adr/0031-own-tokenizers.md](adr/0031-own-tokenizers.md) — Languages without an RSyntaxTextArea lexer that are too large for line rules (TOML, Bicep, KQL) get own `SyntaxHighlighter` objects: one linear pass, no errors flagged, recovery at line starts, perf-tested; Bicep's graph shares its tokens; tm4e, sora-editor and tree-sitter rechecked and rejected.
- [adr/0032-product-name-thoreau.md](adr/0032-product-name-thoreau.md) — The user sees the name Thoreau (window titles, `Thoreau.app`, disk image, User-Agent, docs); the technical name `sluide` stays (repository, packages, classes, artifacts, `~/.sluide`, bundle identifier `dev.sluide.ide`).
- [adr/0033-zooming-images-and-diagrams.md](adr/0033-zooming-images-and-diagrams.md) — Images, SVG, Mermaid and Bicep graphs zoom in the page (explicit px size, not `WebView.zoom`); the page reports every change through `sluideBridge` so the toolbar follows; fit never enlarges; zoom kept across re-renders; shortcuts only on the WebView.
- [adr/0034-project-picker.md](adr/0034-project-picker.md) — Every opened folder is remembered in `~/.sluide/projects.properties` (path → last opened); the project picker, its own Stage, appears at startup without command-line folders and after the last window closes; implicit exit off, the app ends when the picker is cancelled with no window open; failures to open or close show the picker again; missing folders dimmed; rejected: racing implicit exit, a modal Dialog, `settings.properties`.
- [adr/0035-git-log-area.md](adr/0035-git-log-area.md) — Git log as a collapsible area under the editor area, only for followed repositories, collapsed by default (pinned to its header), 30 % when expanded, then its last height in pixels; `git log --branches --remotes --tags --ignore-missing HEAD` (no `--all`, mailmap, UTF-8) loaded lazily in pages of 500 (slow without a commit-graph); refresh on `.git` changes (`gitFolderChanged`, not `refs/`) and by hand; module `git-log` -> `git`; JGit rejected again; partly superseded by 0062 (only changes of what the log reads count, one reload per write).
- [adr/0036-commit-graph-layout.md](adr/0036-commit-graph-layout.md) — Commit graph from our own lane layout over the parents (date order, one pass, incremental across pages, lanes converge at forks, merges open lanes, compacted), stored compactly per row; drawn in the Subject cell left of the text as CSS-coloured `Path`/`Circle` shapes (8 looked-up colours, dark variants, a halo in selected rows), at most 30 lanes drawn and stored per row; JGit `revplot`, `git log --graph` and a Canvas rejected.
- [adr/0037-ref-labels-and-commit-details.md](adr/0037-ref-labels-and-commit-details.md) — Ref labels and commit details in the git log: refs from `git for-each-ref` (peeled tags, symrefs skipped) plus `HEAD` and the current branch, read with every first page; labels at the right end of the Subject cell (local and remote branches of one name grouped, `HEAD` with its branch, ` +N`, coloured tag icons, tooltip with every ref); a details pane right of the table (30 %) loaded lazily with `git show -s`, latest wins, selectable flat text areas, placeholders.
- [adr/0038-changed-files-and-commit-diffs.md](adr/0038-changed-files-and-commit-diffs.md) — Changed files and commit diffs in the git log: `git diff-tree -M` against the first parent (`--root` for root commits), raw blobs via `cat-file` (names on stdin), binary (NUL) and 5 MB checks, hunks from `git diff -U0` of the two blobs; a compacted, coloured file tree above the details (vertical split, loaded with them, latest wins); Show Diff, Open Local File, Copy Path through callbacks wired by `ide`; `FileViewers.openDiff` of given texts in a reused read-only `CommitDiffTab`.
- [adr/0039-git-log-filters.md](adr/0039-git-log-filters.md) — Git log filters: git's own commit limiting (`--grep`, `--author`, revisions, paths, `--first-parent`, `--no-merges`, date/topo order) so paging stays incremental; revisions and paths on stdin, patterns as arguments with a byte-wise fallback for non-ASCII; ERE always, literal text escaped, no `-F`, author patterns case-insensitive by bracket classes; a hash match as the first row (branches not applied); graph only where git rewrites parents (paths, branches) or with first parent only, none under text/user/no-merges; filter bar with popups, per window, not stored.
- [adr/0040-git-log-branches-pane.md](adr/0040-git-log-branches-pane.md) — Git log branches pane: a tree of `HEAD`, local branches, remotes and tags left of the commits (20 %, toggle in the filter bar, not stored) built from the refs the log already reads, folders compacted, Tags collapsed; search by short name; single click selects the branch's commit (loading pages up to 10,000 commits), double-click/Enter sets the Branch filter; remote names split at the first `/`; rejected: an own `git branch` call, navigating by filtering.
- [adr/0041-git-write-operations.md](adr/0041-git-write-operations.md) — Git log changes the repository: checkout, new branch, new tag, rename and delete through the git CLI (`GitBranches`, hooks and config apply) after `--end-of-options`, one at a time on `sluide-git-write` (checkouts up to 10 min, otherwise 60 s; closing the window does not interrupt), new branches created before they are checked out (`switch -c`/`--track` can leave files staged), no editor, git's stderr shown without `hint:` lines, optional locks taken, refresh after each (once, at the end of a hold of the status, since 0062); deletes confirmed (+ force delete for branches `-d` leaves), the current branch never overwritten and orphaning overwrites confirmed; unsaved editors of the repository asked about before a checkout; no smart checkout; names the JVM cannot pass refused, tag messages via stdin; remote branch deletion and network operations deferred.
- [adr/0042-git-log-commit-operations.md](adr/0042-git-log-commit-operations.md) — Git log cherry-pick, revert (merges `-m 1` once confirmed) and reset through `GitCommits`, one commit at a time, nothing started while a merge, rebase or sequence is in progress; empty results cleared, conflicts left with a bar (Continue: marker check of text conflicts, confirmation for binary/deleted/submodule ones, only conflicted paths staged via stdin, `--continue --no-edit`; Abort; other operations shown, left to the terminal); reset asks about orphaned commits and lost local changes; unsaved-editor question names the action.
- [adr/0043-git-log-fetch.md](adr/0043-git-log-fetch.md) — Git log Fetch through `GitRemotes`: `git fetch --prune --recurse-submodules=no` per remote (not `--all`: each failure named, per-remote summary and progress), `skipFetchAll` honoured, tags auto-followed only (no `--tags`/`--prune-tags`), never interactive (`GIT_TERMINAL_PROMPT=0`, ssh `BatchMode=yes` unless the user chose an ssh command or variant; no askpass), 10 min per remote, cancellable (only fetch; same stop as the timeout, descendants too; window close and another folder cancel it), summary from comparing refs, "Fetch Failed" dialog per remote; no Update/pull/push.
- [adr/0044-git-log-compare.md](adr/0044-git-log-compare.md) — Git log compare: Compare with Current as a mode of the log built on the filter (`GitLogFilter.excluded` as `^rev` on `log --stdin`, the bar's other filters on top, Branch set aside and restored), counts of each side under the same filters (`log --left-right --format=%m`, shared argument code) with every first page, ended by a refresh when the ref is gone or checked out; Show Diff with Working Tree / Compare with Local in a non-modal top-level window (not owned, placed at the IDE window's right edge) (`git diff --name-status -M <commit>`, tracked files only, refresh on focus), diff tabs with the commit side in checkout form (`cat-file --batch --filters`) and the live file on the right, hunks by `git diff --no-index --text` of two temporary files without attributes or line-ending conversion (no paths as arguments); no branch-vs-branch, three-dot or commit-vs-commit file diffs.
- [adr/0045-git-log-navigation.md](adr/0045-git-log-navigation.md) — Git log navigation: one revision resolver (`cat-file --batch-check` with `<rev>^{commit}` and `<rev>` on stdin: peeled commit, missing or ambiguous; no `rev-parse` arguments) for hash links (7–40 hex words resolved with the details, RichTextFX `LinkText` for colour, underline and hit-testing) and Go to Hash/Branch/Tag (Shortcut+G popup with completion, messages and Clear Filters in the popup); "In N branches" read lazily by `for-each-ref --contains` on its own thread, 10 s, cached until the refs change; all through `loadUntil`.
- [adr/0046-git-log-file-history.md](adr/0046-git-log-file-history.md) — Git log file history: a closable `History: <name>` tab per (file, start commit) in the area's header next to `Log` (rejected: an editor tab, the path filter), only the shown tab loads; `git log --follow -M --name-status` with the start revision and path on stdin (checked: git takes the one pathspec `--follow` needs from there), pages re-read from the start because `--skip` breaks rename following and restarting at a parent loses merged commits; details, Show Diff, Compare with Local and Show in Log reuse the log's; Show History hooks in explorer and editor tabs wired by `MainWindow`.
- [adr/0047-module-dependencies-and-shared-modules.md](adr/0047-module-dependencies-and-shared-modules.md) — Module dependencies: acyclic, only within a capability family or on small foundation modules, unrelated feature modules wired by `ide` callbacks, shared pieces extracted into small modules (first: `file-icons`), every dependency documented and commented.
- [adr/0048-commit-tab.md](adr/0048-commit-tab.md) — Commit tab of the git log area (Git → Commit…, Shortcut+K; rejected: a window, a modal dialog): tree of tracked and unversioned changes with tri-state checkboxes kept by path, message, Amend; `git add` of checked untracked files, then `git commit --only [--amend] --cleanup=whitespace -F -` with `--literal-pathspecs` and the paths in a NUL-separated pathspec file (message on stdin), renames with both paths; refused while anything is in progress or conflicted; reads on `sluide-git-commit`, the commit on `sluide-git-write`, 10 min, cancellable; draft kept per window until another folder; verified with git 2.53.
- [adr/0049-push.md](adr/0049-push.md) — Push dialog (Git → Push…, Shortcut+Shift+K; header up arrow; Commit and Push): non-modal window owned by the IDE window; target from push config (pushRemote, pushDefault, upstream), editable, "New" by the remote-tracking ref of the fetch refspecs; outgoing commits (max 1000) with All against the merge base; `git push --porcelain --recurse-submodules=no [--set-upstream] [--force-with-lease=<ref>:<explicit oid>]`, never plain `--force`; Force Push confirmed and disabled for main/master; no auto-fetch; rejections explained in the error dialog; `sluide-git-push` reads, the push on `sluide-git-write`, cancellable; verified with git 2.53.
- [adr/0050-focus-when-a-file-tab-is-shown.md](adr/0050-focus-when-a-file-tab-is-shown.md) — One focus rule for file tabs (`FileView.focus()`, deferred until the target is in a scene): opening a file or choosing its tab always focuses it, a tab selected in place of a closed or replaced one only if the editor area had the focus; the source for code views and previews in Source/Split, the web view for images, previews shown alone and zooming previews in Split (Mermaid, Bicep); caret and scroll kept; `focusText()` stays the immediate focus after a diff; amends ADR 0033.

- [adr/0052-hardening-how-git-is-started.md](adr/0052-hardening-how-git-is-started.md) — `GitCli` removes the variables that point git at another repository (`git rev-parse --local-env-vars`, asked only if one is set; git 2.53's list as fallback; configuration variables kept, as git keeps them) and keeps reads from running a `core.fsmonitor` hook (`-c core.fsmonitor=false` when the setting is a command, read with `git config --type=bool` and kept per folder while its configuration's content stays; git's own daemon kept); filters (clean on `git status`, smudge for the diff) and hooks on writes still open.
- [adr/0053-project-trust.md](adr/0053-project-trust.md) — Project trust: tools implement `ProjectTrustCheck` (module `project-trust`, injected as a list into the window's `ProjectTrust`), which says what a folder would make them run; nothing found runs without asking, findings ask once, with one fingerprint over all checks stored per folder (`~/.sluide/project-trust.properties`, asked again when the findings change); a tool whose check found something stays off until the folder is trusted; partly superseded by 0062 (git's check reruns only when a stamp of its inputs changed).
- [adr/0054-keep-source-files-small.md](adr/0054-keep-source-files-small.md) — Keep source files small: production files aim for under ~500 lines, over 600 they are split by responsibility when next changed substantially (`.claude/scripts/check-file-sizes.sh` reports, never fails); `GitCli` became a process core plus `internal` extension read files by area (`GitCliLog.kt`, `GitCliRefs.kt`, …), `GitLogView` a coordinator plus `internal` components (`CompareBar`, `CommitDiffs`, …) reached by tests through the view's member.

- [adr/0060-logging-conventions.md](adr/0060-logging-conventions.md) — Logging conventions: INFO start/end of own work with duration, WARNING for user-facing failures and git on the JavaFX thread, ERROR with stack trace, no secrets, hot paths only when slow; every git command numbered (`git#n`) with start, exit, duration and, for failed reads, the start of stderr (4 KB kept, 500 characters logged; partly supersedes 0013); `.git` batches and status cycles logged; FX watchdog logs a blocked JavaFX thread with its stack.
- [adr/0061-background-tasks.md](adr/0061-background-tasks.md) — Background tasks: a per-window registry (`BackgroundTasks`, module `background-tasks`, reached by file views through `FileViewHost.windowService`) shown as an inline list under the file explorer, IntelliJ as the model but no popup; a task appears after 0.5 s, at most 4 rows plus "+N more", ✕ only where the work can be cancelled; one numbered start and one end line per task (finished, failed, cancelled, or abandoned when the window closes, ADR 0060); registered: git writes, git log and history pages, git status, trust checks, exports, HTTP and token requests; `BackgroundTasks.forTests` for other modules' tests.
- [adr/0062-git-concurrency.md](adr/0062-git-concurrency.md) — What git work runs in parallel and what is queued: editor change markers off the JavaFX thread (`GitStatusService.diffAsync` on a per-window `sluide-git-diff` thread, newest request per file wins, superseded git stopped through `GitCancellation`; `EditorArea.diffOf` asynchronous, old markers kept until the answer, unmodified files answered at once); `.git` stamps (the state by size, time and inode, incl. reftable; the trust inputs by content and permissions, incl. `.git` redirects, `commondir`, `gitdir`) decide whether a batch of `.git` rechecks trust, counts `gitFolderChanged` or runs anything; git writes hold refreshes and end in one cycle; superseded reads of the git log (pages, details, branch containment, file diffs, Push dialog) stop their git; details compared by hash; partly supersedes 0013, 0015, 0021, 0035, 0041 and 0053.
- [adr/0063-git-log-rebase.md](adr/0063-git-log-rebase.md) — Git log rebases the current branch onto another local or remote branch (`GitRebases`): `git -c rebase.updateRefs=false -c rebase.rebaseMerges=false rebase --merge --no-autostash --no-fork-point --end-of-options <refname>`, 10 min, not cancellable; nothing runs when the other branch is already contained (checked at run time, not by `for-each-ref --merged`), dropped merges confirmed first; local changes left to git's refusal; entries in the branches pane's menu and in per-branch submenus of the log's commit menu; a rebase in progress (`GitPendingRebase`, also from a terminal, `git am` stays terminal-only) continued (pick's marker check, only unmerged paths staged, `GIT_EDITOR=:`, empty commits skipped unless unstaged changes), skipped or aborted, with the stopped dialog and the pending bar's Continue/Skip/Abort (Skip and Abort ask first); ignored files not checked; partly supersedes 0042.
