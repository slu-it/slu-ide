# SluIde documentation index

Entry point for agents: read this file first, then open only the documents relevant to your task.
Keep it up to date: every new ADR or feature description must be added here with a one-line summary.

## Overview
- [architecture.md](architecture.md) — Module layout, dependency rules, runtime startup, CI and release process.

- [testing.md](testing.md) — Unit vs. TestFX UI tests, `uiTest` task, display handling locally and in CI, how to write UI tests, running and screenshotting the app in a headless sandbox.

## Decisions (ADRs)
- [adr/0001-tech-stack.md](adr/0001-tech-stack.md) — Kotlin on JDK 25, Spring Boot, JavaFX, Gradle multi-module build.
- [adr/0002-spring-inside-javafx.md](adr/0002-spring-inside-javafx.md) — A non-web Spring context is started and stopped by the JavaFX `Application`; UI parts are Spring beans; partly superseded by ADR 0014 (window beans created per window on the FX thread).
- [adr/0003-javafx-platform-jars.md](adr/0003-javafx-platform-jars.md) — JavaFX comes from the OpenJFX Gradle plugin; fat jars are platform-specific, so releases are built and published per OS/arch (no Windows).
- [adr/0004-file-viewer-selection.md](adr/0004-file-viewer-selection.md) — Viewers are asked in turn whether they can open a file, `DefaultTextFileViewer` last; no viewer means the file is not opened.
- [adr/0005-syntax-highlighting.md](adr/0005-syntax-highlighting.md) — Code views render with RichTextFX and tokenize with the RSyntaxTextArea lexers behind our own `SyntaxHighlighter`; alternatives considered.
- [adr/0006-file-watching.md](adr/0006-file-watching.md) — JDK `WatchService` behind `FileWatcher`, watching only loaded folders, the folders of open files and the repository's `.git` (not recursive); combined events, watches renewed for recreated folders; macOS polls every 2 s.
- [adr/0007-terminal.md](adr/0007-terminal.md) — Terminals use pty4j and the JediTerm core (from JetBrains' repository, restricted to its group) with our own JavaFX canvas view; alternatives considered.
- [adr/0008-settings.md](adr/0008-settings.md) — Settings live in `modules/settings` as Spring beans with JavaFX properties, stored in `~/.sluide/settings.properties` (keys and formats; an unreadable file is never replaced); a setting changes only once stored; dialog built from `SettingsPage` beans.
- [adr/0009-themes.md](adr/0009-themes.md) — Light/dark/system theme: scene colour-scheme preferences, `theme.css` re-tinting Modena, `@media (prefers-color-scheme: dark)` rules only in stylesheets with their own colours; WebView pages follow ADR 0016; single-class selectors only in dark blocks.
- [adr/0010-docker-sandbox.md](adr/0010-docker-sandbox.md) — Docker sandboxes run as the process of a terminal tab, only in folders strictly below the home folder (real paths), checked in the menu and again on start.
- [adr/0011-native-app-packaging.md](adr/0011-native-app-packaging.md) — jpackage builds SluIde.app / a disk image with a compressed jlink runtime (`:ide:jpackageImage`, `:ide:jpackageDmg`), attached to GitHub releases; not notarized, allowed once via Open Anyway.
- [adr/0012-file-icons.md](adr/0012-file-icons.md) — File explorer icons from Ikonli's Material Design Icons pack (one style), covering every file type icon of the pack, chosen by folder state, file name, extension and readability, coloured per type in CSS; pack comparison.
- [adr/0013-git-status.md](adr/0013-git-status.md) — Git status from `git status --porcelain=v2 --ignored` (no JGit, no own `.gitignore` parser), checked for at startup, followed only for folders with `.git`, refreshed in the background on explorer changes, F5 and changes directly in `.git`; a failed run keeps the last status; markers in the explorer.
- [adr/0014-project-windows.md](adr/0014-project-windows.md) — One project per window: Open Folder opens a new window unless the window has no folder yet; Spring scope `window` for per-window beans (`ProjectWindows`); one confirmation when closing a window with running tabs.
- [adr/0015-git-diff.md](adr/0015-git-diff.md) — Side-by-side diff against `HEAD` from `git diff -U0`/`git cat-file` (no diff library), synchronous per file, filler rows for aligned scrolling; partly superseded by ADR 0021 (files open in the editor with change markers, the diff on demand).
- [adr/0016-markdown-preview.md](adr/0016-markdown-preview.md) — Markdown preview: commonmark-java renders sanitised HTML (jsoup) into a JavaFX WebView beside the source; native JavaFX nodes rejected; javafx.web grows the fat jar by ~48 MB; partly superseded by ADR 0017 (pages that navigate on their own).
- [adr/0017-webview-previews.md](adr/0017-webview-previews.md) — One `PreviewFileView` (source beside a WebView) for all rendered formats; HTML loaded by URL from the local server (ADR 0018) with its scripts off by default, navigations without user input stop the preview; bundled KaTeX and Mermaid; notebooks rendered from their JSON.
- [adr/0018-html-preview-server.md](adr/0018-html-preview-server.md) — HTML previews are served from a loopback HTTP server confined to the project folder (no hidden files, no symlinks out), since `file:` pages' scripts can read every local file.
- [adr/0019-word-diff.md](adr/0019-word-diff.md) — Changed words within modified lines come from a small token LCS over each modified block of git's line diff (no `git --word-diff`, no library), earliest matches preferred, blocks over a million steps left out.
- [adr/0020-editing-and-saving-files.md](adr/0020-editing-and-saving-files.md) — Code, plain text and preview sources are edited in RichTextFX `CodeView`s (`EditableFileView`) with plain-text undo; dirty from the undo mark; explicit save in place keeping line endings; saved text as baseline for changes on disk (`DiskChange`: ignore, reload minimally, banner); prompts before closing; previews render on save; highlighting in the background after a pause.
- [adr/0021-change-markers-and-diffs-on-demand.md](adr/0021-change-markers-and-diffs-on-demand.md) — Files always open in the editor; `Gutter` replaces `LineNumberFactory` with line numbers, change markers from git's diff (`LineMarkers`, moved along with unsaved edits) and a column hook; the side-by-side diff of the saved file is shown on demand over the kept editor (View → Show Changes, Shortcut+Shift+D; Edit/Escape back; clicking a marker); partly supersedes ADR 0015.
- [adr/0022-editor-key-bindings.md](adr/0022-editor-key-bindings.md) — Editor keys as a wellbehavedfx `InputMap` per code view (precedence over RichTextFX's, only while the text has the focus, editing keys only while editable) rather than menu accelerators; Shortcut modifier; keys after IntelliJ/VS Code; Shortcut+/ by character, Shortcut+Shift+7 by key; one `TextEdit` = one undo step (Replace All: one multi-change); search on the FX thread within a 200 ms budget, at most 10,000 marked matches; no command registry yet.
- [adr/0023-indentation-from-editorconfig.md](adr/0023-indentation-from-editorconfig.md) — Indentation from `.editorconfig` via ec4j-core 1.1.1 (Apache-2.0, no dependencies, used by ktlint), each value else detected from the file, else 4 spaces; read when a file opens; no whitespace or final-newline rewrites on save.
- [adr/0024-file-operations-in-the-explorer.md](adr/0024-file-operations-in-the-explorer.md) — New file/folder, rename and delete in the explorer: `FileOperations` with checked single names, rename within the folder (case-only renames over a temporary name), permanent delete without trash behind a confirmation counting unsaved files; open tabs follow renames (`FileView.moved`, else reopened) and close after a delete.
- [adr/0025-http-client.md](adr/0025-http-client.md) — HTTP client module, the supported subset of IntelliJ's `.http` format, variable lookup order (dynamic, environment, in-file), body files and unresolved variables, unverified IntelliJ behaviours.
- [adr/0026-http-client-window-session.md](adr/0026-http-client-window-session.md) — Per-window `HttpClientSession` (cookies, tokens, clients, chosen environments) found through `FileViewHost.windowService`; the public code editor API of `file-viewers` (`CodeEditors`, `CodeEditor`, `CodeDisplay`, `SourceFileViewer`).
- [adr/0027-http-client-sending.md](adr/0027-http-client-sending.md) — Requests on the JDK `HttpClient` off the FX thread: restricted headers and `allowRestrictedHeaders=host`, defaults, decompression, 50 MB cap, redirects, timeouts, cookie jar, Basic and Digest, default proxy selector.
- [adr/0028-http-client-secrets.md](adr/0028-http-client-secrets.md) — Secrets only from the environment files (warning when git would commit the private one), OAuth2 grants and in-memory tokens per window (refresh, failures not cached), client certificates and passphrase prompts, trust-all per environment.
- [adr/0029-file-name-and-shebang-matching.md](adr/0029-file-name-and-shebang-matching.md) — Viewers match by extension, exact name or name pattern (exact name > extension > pattern, Spring order only for ties), extensionless files by shebang after all names; small formats without a lexer get line rules on the plain lexer, which is skipped; TOML, Bicep, KQL postponed.
- [adr/0030-masking-env-values.md](adr/0030-masking-env-values.md) — `.env` values are masked by a `masked` style overlay on the `CodeView` (text untouched, so copy/find/save/undo work), applied with every change; caret line and selected find match revealed, Show values toggle per tab; whole lines, hover reveal and masked diffs rejected.
- [adr/template.md](adr/template.md) — Template for new ADRs.

## Features
- [features/open-folder.md](features/open-folder.md) — File → Open Folder… or `SluIde [folder…]` on the command line opens a folder in the empty window or a new one (one project per window), closing a window asks to save unsaved files, then once while its tabs run something.
- [features/previews.md](features/previews.md) — Rendered previews beside the source: HTML (served from the project by a local server, scripts off unless toggled, links leave via the host, pages navigating on their own stop), SVG, sortable CSV/TSV tables, Jupyter notebooks with outputs; image files on a checkered page.
- [features/file-explorer.md](features/file-explorer.md) — Tree view of the project folder incl. hidden files (not `.git`), lazy loading, sort order, opening files (double-click/Enter), live updates and Refresh (context menu/F5), file icons, markers, New File/New Folder/Rename (F2)/Delete in the context menu.
- [features/editor-tabs.md](features/editor-tabs.md) — Central area with one closable tab per open file or other `EditorTab` (e.g. terminals), ● for unsaved changes, save and save-all, asking to save before closing, confirmation before closing running tabs, reload on changes on disk, following renames and closing on deletes in the explorer, change markers and the diff on demand over the kept editor, tab context menu (close others/left/right/all), reordering by drag and drop, scroll arrows and a dropdown for tabs that do not fit.
- [features/settings.md](features/settings.md) — File → Settings… (Ctrl+,): page tree, OK/Apply/Cancel (applied only once stored), Display → Appearance (Light/Dark/System theme), Display → Fonts (font, size, style for explorer, editor, terminal) with preview, stored per user.
- [features/terminal.md](features/terminal.md) — Terminal → New Terminal (Ctrl+Shift+T) opens the user's shell in the project folder as an editor tab, or an error if the shell cannot start; keys sent to the shell (incl. Ctrl+O), colours, full-screen programs, mouse, scrollback, copy/paste, confirmation before closing while programs run.
- [features/docker-sandbox.md](features/docker-sandbox.md) — Docker Sandbox → Claude Code (`sbx run claude .`) / Environment (`sbx env run`, needs `sbxenv.yaml`) in a terminal tab, only below the home folder; the menu is disabled without `sbx`; an error dialog says why a sandbox cannot start.
- [features/git-status.md](features/git-status.md) — Git status in the file explorer (red unversioned, green added, blue modified, orange ignored): coloured file and ignored-folder names, bubbles on folders for their content, when it updates.
- [features/markdown-preview.md](features/markdown-preview.md) — Markdown files open as highlighted source beside a rendered, sanitised preview with math (KaTeX) and Mermaid diagrams; Source / Split / Preview toolbar, preview scrolls with the source, links open in the browser or a tab, theme-aware.
- [features/git-diff.md](features/git-diff.md) — Change markers against `HEAD` in the editor's gutter (green added, blue modified, grey tick for removed), following unsaved edits; View → Show Changes (Ctrl/Cmd+Shift+D) or a click on a marker shows the saved file side by side with `HEAD` (aligned, scrolled together, changed words, change navigation), Edit/Escape go back to the editor.
- [features/text-editing.md](features/text-editing.md) — Editing code, plain text and preview sources: ● for unsaved changes, File → Save (Ctrl/Cmd+S) and Save All, in place with the file's line endings, changes on disk (reload keeping caret and undo, banner with Reload / Keep mine), deleted files, Save / Don't Save / Cancel before closing tabs and windows, background highlighting, change markers in the gutter; editing keys (Enter/Tab indentation from `.editorconfig`, duplicate/delete/move lines, comments per language), find bar with marked matches and replace, go to line.
- [features/file-watching.md](features/file-watching.md) — `FileWatcher`: per-directory watches, combined events on the FX thread, deleted folders watched again when recreated, used by explorer, editor and git; macOS polls every 2 s.
- [features/file-viewers.md](features/file-viewers.md) — `FileViewer` extension point (`FileView` with `reload`, `dispose`, `host`, `moved`), viewer selection, `EditableFileView` (incl. `showChanges`), the public gutter column hook `GutterColumns`, the plain-text `DefaultTextFileViewer` (text detection rules), the syntax-highlighted, editable `CodeFileViewer`s (matched by extension, file name, name pattern, the best match winning (exact name > extension > pattern), or, for extensionless files no name matches, shebang; Python, Kotlin, Java, JavaScript, TypeScript, JSX, TSX, JSON, XML, Vue, Svelte, YAML, CSS, SCSS, Sass, LESS, MDX, SQL, shell, PowerShell, Dockerfile, Makefile, INI and config files, ignore files, `.git-blame-ignore-revs`, SSH config, Caddyfile, `.env`), line rules for small formats without a lexer, `forLanguage` names, preview viewers (Markdown, HTML, SVG, CSV, cookie jars, notebooks, Mermaid, PEM), `EnvFileViewer` masking, the image viewer and side-by-side diff views; the public code editor API for other modules (`CodeEditors`, `SourceFileViewer`, `Highlighters`, `windowService`).
- [features/env-files.md](features/env-files.md) — `.env`, `.env.*`, `*.env` highlighted with their values masked (caret line and selected find match revealed, Show values toggle off on every open), text untouched for copy/find/save, placeholder files (`.example`, `.sample`, `.template`) unmasked, diffs unmasked.
- [features/http-client.md](features/http-client.md) — `.http`/`.rest` files: request format, variables and environments (public + private files), OAuth2 and client certificates, running from the toolbar, Shortcut+Enter or gutter icons, the response pane, what is not supported.
